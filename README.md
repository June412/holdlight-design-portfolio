# HoldLight — Design Portfolio

**CPT208 — Human-Centric Computing**

A website presenting the user research, design iterations and evaluation of HoldLight, a climbing assistance app for blind and low-vision climbers. It documents how route previews and audio guidance developed through the design process.

[Live Portfolio](https://yuuu-05.github.io/CPT208-ClimbProject-C2-4/) · [Application Code](https://github.com/June412/holdlight-accessible-climbing) · [Demo Video](https://github.com/Yuuu-05/HoldLight/releases/tag/project-demo) · [Poster](assets/documents/HoldLight-Poster.pdf)
