# HoldLight — Design Portfolio

Design process and project materials for HoldLight, a mobile-first climbing assistance system for blind and low-vision climbers. The project explores layered route previews, brief audio guidance, and ways to recover when guidance becomes uncertain.

[Live Project Portfolio](https://yuuu-05.github.io/CPT208-ClimbProject-C2-4/) · [Application Source Code](https://github.com/June412/holdlight-accessible-climbing) · [Demo Video](https://github.com/Yuuu-05/HoldLight/releases/tag/project-demo) · [Poster](assets/documents/HoldLight-Poster.pdf)

## Contents

The website presents five parts of the design process:

1. **Why & Gap** — the accessibility problem and project motivation.
2. **User Requirements** — the needs informing the design.
3. **Iteration & Alternatives** — design development and alternatives.
4. **Implementation** — the application and its interaction approach.
5. **Evaluation & Reflection** — evaluation and lessons from the project.

Project materials also include:

- `assets/documents/`: project poster.
- `assets/videos/`: prototype demonstrations.

The application source code is maintained separately in [HoldLight — Accessible Climbing](https://github.com/June412/holdlight-accessible-climbing), forked from the [original application repository](https://github.com/Yuuu-05/HoldLight). The final demo is available as a release attachment in the original repository.

## View Locally

This is a static HTML, CSS, and JavaScript website. Clone the repository and serve it locally:

```bash
git clone https://github.com/June412/holdlight-design-portfolio.git
cd holdlight-design-portfolio
python -m http.server 8000
```

Open http://localhost:8000 in your browser.
